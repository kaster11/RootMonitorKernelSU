# Root Monitor for Android 16 + KernelSU

پروژه‌ی شروع Kotlin/Android Studio برای مانیتورینگ پردازش‌ها با دسترسی `su`.

## ساخت
1. Android Studio به‌روز را نصب کنید.
2. این پوشه را باز کنید و اجازه دهید Gradle Sync انجام شود.
3. روی گوشی USB debugging را فعال کنید و برنامه را اجرا کنید.
4. درخواست دسترسی Root را در KernelSU تأیید کنید.

## وضعیت فعلی و محدودیت‌ها
- RAM از `/proc/<pid>/status` خوانده می‌شود.
- CPU از اختلاف شمارنده‌های `/proc/<pid>/stat` بین نمونه‌ها تخمین زده می‌شود؛ درصدها تقریبی‌اند.
- فهرست پردازش‌ها از `/proc` ساخته می‌شود و نام برنامه بر اساس UID نگاشت می‌شود. چند پردازش با UID مشترک ممکن است نام یکسان داشته باشند.
- آمار شبکه از `/proc/net/xt_qtaguid/stats` خوانده می‌شود، اگر کرنل آن را ارائه کند. بسیاری از کرنل‌های جدید Android 16 این فایل را ندارند؛ در آن حالت برنامه صریحاً اعلام می‌کند که آمار شبکه در دسترس نیست.
- فایروال از `iptables` و `ip6tables` استفاده می‌کند. بعضی رام‌ها از nftables استفاده می‌کنند یا باینری‌های سازگار ندارند. در آن دستگاه‌ها این بخش به پیاده‌سازی مخصوص همان رام/کرنل نیاز دارد.
- قوانین این نمونه پس از ریبوت ماندگار نیستند. همچنین حذف قانون با `-D` ممکن است در صورت وجود قوانین مشابه یا تغییر ترتیب قوانین دقیقاً قانون موردنظر را حذف نکند؛ برای انتشار عمومی باید chain اختصاصی و مدیریت idempotent اضافه شود.
- این کد نمونه‌ی اولیه است و قبل از استفاده روزمره باید روی دستگاه هدف تست شود. بستن اینترنت بر اساس UID روی برنامه‌های سیستمی ممکن است باعث اختلال شود.
- برای انتشار در Google Play، `QUERY_ALL_PACKAGES` مشمول محدودیت سیاست‌های فروشگاه است؛ برای نصب مستقیم APK معمولاً مسئله متفاوت است.

## کامپایل آنلاین با GitHub Actions
1. یک repository جدید در GitHub بسازید و فایل‌های همین پروژه را در آن آپلود کنید.
2. به زبانه‌ی **Actions** بروید.
3. گردش‌کار **Build Android APK** را انتخاب و روی **Run workflow** بزنید.
4. پس از پایان موفق، اجرای workflow را باز کنید و از بخش **Artifacts** فایل `RootMonitor-debug-apk` را دانلود کنید.
5. ZIP آرتیفکت را استخراج کنید؛ فایل `app-debug.apk` داخل آن است.

این گردش‌کار APK دیباگ می‌سازد و فایل فقط وقتی ارائه می‌شود که build موفق باشد. برای این کار باید حساب GitHub داشته باشید و سورس پروژه را به repository خودتان ارسال کنید.
